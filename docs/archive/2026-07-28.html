Critical OpenWrt DHCPv6 Flaw Could Let Unauthenticated Attackers Run Code as Root

Unauthenticated attackers can exploit a critical flaw in OpenWrt's DHCPv6 service to execute arbitrary code, posing a severe risk to network integrity.

Who should care: Network administrators and security teams managing OpenWrt devices should prioritize this issue.
Attack path: An attacker can send specially crafted DHCPv6 packets to the vulnerable service, allowing them to execute arbitrary code with root privileges.
Why this matters now: Useful context for teams tracking where attacker pressure is building.
In plain English: A critical vulnerability in OpenWrt allows attackers to run code as root without authentication.
cve network openwrt
  • OpenWrt released version 24.10.8 to address a critical stack overflow vulnerability in its DHCPv6 service, identified as CVE-2026-53921. This flaw, rated 9.8 on the CVSS scale, allows unauthenticated attackers to overwrite a stack buffer in the odhcpd service through crafted DHCPv6 packets.
  • If exploited, this vulnerability could allow attackers to gain root access to affected devices, leading to potential network compromise and unauthorized control. Given that the DHCPv6 service is enabled by default, many devices could be at risk, making immediate patching essential.
  • An attacker can send specially crafted DHCPv6 packets to the vulnerable service, allowing them to execute arbitrary code with root privileges.
  • Watch next: Monitor for updates from OpenWrt regarding further patches or advisories related to this vulnerability.
Key terms
  • CVE - Common Vulnerabilities and Exposures, a list of publicly disclosed cybersecurity vulnerabilities.
  • DHCPv6 - Dynamic Host Configuration Protocol for IPv6, a network protocol used to assign IP addresses and other network configuration to devices.
Defender focus
  • Implement monitoring for unusual DHCPv6 traffic patterns.
  • Ensure all OpenWrt devices are updated to version 24.10.8 or later.
  • Review firewall rules to limit access to the DHCPv6 service from untrusted networks.
Do now
  • Patch OpenWrt devices to version 24.10.8 immediately.
  • Conduct a risk assessment of devices running OpenWrt in your environment.
  • Increase monitoring for any signs of exploitation attempts targeting DHCPv6 services.
Watch next: Monitor for updates from OpenWrt regarding further patches or advisories related to this vulnerability.

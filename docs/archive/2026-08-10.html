Solidity Pro VS Code Extensions Steal Crypto Wallets, API Keys, and Credentials

Malicious VS Code extensions are actively stealing crypto wallets and credentials, posing immediate risks to developers and users in the blockchain space.

Who should care: Development teams working with blockchain technologies and users of VS Code extensions related to cryptocurrency.
Attack path: Attackers leverage malicious extensions to gain access to sensitive information stored in users' browsers, enabling them to steal crypto assets and credentials.
Why this matters now: Useful context for teams tracking where attacker pressure is building.
In plain English: Two malicious VS Code extensions have been identified that steal sensitive information from users.
ransomware cve cloud
  • Cybersecurity researchers have discovered a malicious extension named Solidity Pro for Microsoft Visual Studio Code that delivers a browser wallet and credential stealer. The extensions, 'helper-beeps.solidity-pro' and 'web3devtoolsx.solidity-pro', are no longer available on Open VSX but may still pose risks to users who previously installed them.
  • The theft of crypto wallets and API keys can lead to significant financial losses for developers and users in the blockchain ecosystem. As these tools are commonly used for development, the potential for widespread impact is high, especially among those who may not be aware of the risks.
  • Attackers leverage malicious extensions to gain access to sensitive information stored in users' browsers, enabling them to steal crypto assets and credentials.
  • Watch next: Monitor for any updates from Microsoft regarding the removal of these extensions and any new threats that may arise.
Key terms
  • Malicious Extension - a software add-on that is designed to harm or exploit users' systems.
  • Credential Stealer - a type of malware that captures sensitive information such as usernames and passwords.
Defender focus
  • Implement monitoring for unauthorized VS Code extensions in development environments.
  • Review access logs for unusual activity related to crypto wallets and API keys.
  • Educate developers on the risks of installing third-party extensions from unverified sources.
Do now
  • Immediately remove any suspicious VS Code extensions from development environments.
  • Conduct a security audit of systems to identify potential breaches.
  • Update security policies to restrict the installation of unverified extensions.
Watch next: Monitor for any updates from Microsoft regarding the removal of these extensions and any new threats that may arise.

New cPanel Critical Flaw Could Let Hosting Customers Run SQL as Database Root

A critical flaw in cPanel could allow hosting customers to execute SQL commands with elevated privileges, posing a significant risk to database integrity.

Who should care: Database administrators and security teams managing cPanel environments should prioritize this issue.
Attack path: An attacker with valid cPanel credentials could leverage this flaw to execute SQL commands as the database root, gaining unauthorized access to sensitive data and administrative functions.
Why this matters now: A live patch or vendor fix gives defenders something concrete to validate.
In plain English: cPanel has patched a serious vulnerability that could let users run SQL as the database root, which is a major security concern.
cve cpanel database
  • cPanel released a security patch addressing a vulnerability tracked as CVE-2026-58048, which allows authenticated users to execute SQL commands in the database's root context. This flaw breaches the privilege boundary between individual cPanel accounts and the server's administrative database identity. The patch also addresses two additional security issues.
  • If exploited, this vulnerability could lead to unauthorized access and manipulation of sensitive data across multiple hosting accounts, potentially affecting numerous customers. The elevated privileges could allow attackers to compromise the entire database, leading to data breaches or service disruptions.
  • An attacker with valid cPanel credentials could leverage this flaw to execute SQL commands as the database root, gaining unauthorized access to sensitive data and administrative functions.
  • Watch next: Monitor for any reports of exploitation attempts or additional vulnerabilities related to cPanel.
Key terms
  • cPanel - a web hosting control panel that provides a graphical interface and automation tools to simplify the process of hosting a website.
  • SQL - Structured Query Language, a standard programming language used to manage and manipulate databases.
Defender focus
  • Ensure all cPanel installations are updated with the latest security patches.
  • Monitor database logs for unusual SQL execution patterns that may indicate exploitation.
  • Review user access controls to limit the number of accounts with elevated privileges.
Do now
  • Immediately apply the cPanel security patch to all affected systems.
  • Audit user accounts and permissions to ensure least privilege access.
  • Implement monitoring for any suspicious database activity.
Watch next: Monitor for any reports of exploitation attempts or additional vulnerabilities related to cPanel.

Keyv-Linked npm Worm Poisons Hundreds of Packages, Plants Claude Code and VS Code Hooks

The Keyv-linked npm worm has compromised hundreds of packages, posing a significant threat to software supply chains and potentially leading to widespread credential theft.

Who should care: Development teams using npm packages, particularly those relying on Keyv and related libraries, should be vigilant.
Attack path: An attacker can leverage the compromised npm packages to execute malicious code, potentially stealing user credentials and gaining unauthorized access to systems.
Why this matters now: Useful context for teams tracking where attacker pressure is building.
In plain English: A credential-stealing npm worm has infected hundreds of packages, affecting multiple organizations.
npm malware supply chain
  • On August 4, 2026, a credential-stealing npm worm linked to the Keyv package was identified, spreading to hundreds of other packages. SafeDep reported 353 poisoned versions across 79 package names, while Aikido noted at least 868 affected packages in total.
  • This incident highlights vulnerabilities in the npm ecosystem, where malicious code can propagate quickly across numerous packages. Organizations relying on these packages may face significant security risks, including unauthorized access to sensitive credentials.
  • An attacker can leverage the compromised npm packages to execute malicious code, potentially stealing user credentials and gaining unauthorized access to systems.
  • Watch next: Monitor for updates from npm regarding the affected packages and any patches released to mitigate this threat.
Key terms
  • npm - a package manager for JavaScript that allows developers to share and reuse code.
  • worm - a type of malware that replicates itself to spread to other systems.
Defender focus
  • Identify and audit all npm packages in use for potential vulnerabilities.
  • Implement monitoring for unusual access patterns related to credential usage.
  • Ensure that all development environments are updated with the latest security patches.
Do now
  • Immediately review and update all npm packages to their latest secure versions.
  • Conduct a security audit of systems that may have been exposed to the compromised packages.
  • Educate development teams on the risks associated with third-party package dependencies.
Watch next: Monitor for updates from npm regarding the affected packages and any patches released to mitigate this threat.

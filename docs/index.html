n8n Sandbox Escape Lets Workflow Editors Run OS Commands as the n8n Process

An unpatched vulnerability in n8n could allow authenticated users to execute arbitrary OS commands, posing a significant risk to server integrity.

Who should care: Development and operations teams using n8n for automation workflows should be particularly vigilant.
Attack path: An attacker with access to the n8n workflow editor could leverage this vulnerability to execute arbitrary commands on the server, gaining unauthorized access to system resources.
Why this matters now: A live patch or vendor fix gives defenders something concrete to validate.
In plain English: A serious flaw in n8n allows workflow editors to run OS commands, requiring immediate attention.
n8n cve vulnerability
  • n8n has identified and patched a high-severity sandbox escape vulnerability that enables authenticated workflow editors to execute operating system commands on the server. This flaw was discovered during an investigation into a previous fix for CVE-2026-27577. The affected versions are 2.32.0 to below 2.32.1, with patches available in versions 2.31.5 and later.
  • If exploited, this vulnerability could allow attackers to gain control over the server, leading to data breaches or service disruptions. Organizations using n8n for automation must prioritize patching to prevent potential exploitation that could compromise sensitive information or operational capabilities.

malware phishing cybercrime
